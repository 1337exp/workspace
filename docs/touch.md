# Сенсорное управление

Решения, на которые мы опирались, и что осталось проверить на настоящем планшете.

## Принцип

Один набор событий (pointer events), разное поведение по `pointerType`:

- **`mouse` и `pen`**: прежнее поведение. Перо (Apple Pencil, стилус) считаем мышью: оно рисует рамку и тянет ноды, как левая кнопка.
- **`touch`** (палец): своя раскладка, потому что у сенсора другая частота действий. Чаще всего на планшете двигают холст, а не добавляют ноду, и рамка выделения нужна редко.

Универсальное решение здесь плохо: тап по пустому месту на сенсоре ещё и снимает выделение, поэтому нельзя вешать на него палитру.

## Раскладка жестов

| Мышь | Палец |
|---|---|
| ЛКМ по ноде: выбрать, тянуть: двигать | **Тап** по ноде: выбрать, тянуть: двигать |
| ЛКМ по пустому месту: рамка выделения | **Один палец по пустому месту: двигает холст** |
| Правая или средняя кнопка: двигать холст | **Два пальца:** двигать и масштабировать щипком |
| Колесо: масштаб | Щипок |
| Правый клик по пустому месту: палитра нод | **Долгое нажатие** (0.5 с) на пустом месте |
| Двойной клик: переименовать группу или поставить точку на связь | **Двойной тап** |
| Ctrl/Shift + клик: добавить к выделению | **Режим «Выделение»** в тулбаре: тап по ноде добавляет или снимает её |
| Delete | Кнопка «Удалить» в тулбаре |
| Рамка выделения | Режим «Выделение» (один палец рисует рамку) или **двойной тап и сразу протянуть** |
| Наведение показывает пины | Пины видны бледно всегда, у выбранной ноды ярко |

Тап (палец сдвинулся меньше 8 px и лежал меньше 0.3 с) по пустому месту снимает выделение.

## Что ещё учтено

- **Крупные цели касания** при `(pointer: coarse)`: пины 44 px, зоны граней 28 px, углы 32 px, кольцо вокруг точки, попадание по связи 30 px.
- **Второй палец отменяет начатый жест** (тянули ноду, и лёг второй палец, значит, это щипок). Когда один палец поднят, оставшийся продолжает двигать холст без скачка.
- **Палитра по долгому нажатию** не ставит фокус в поле поиска: иначе виртуальная клавиатура закрыла бы список.
- **Браузерные жесты** выключены на холсте (`touch-action: none`), нет выделения текста и всплывающей «лупы», нет оттягивания страницы.
- **Нативный `dblclick`** на сенсоре игнорируется: двойной тап распознаём сами, иначе действие сработало бы дважды.

## Отладка

Открой приложение с `?debug=touch`: в углу покажется последний распознанный жест и число пальцев.
Проверять удобно в DevTools (режим устройства, Toggle device toolbar): там `pointer: coarse` и мультитач (Shift + перетаскивание двумя пальцами).

## Распознаватель

Логика жестов вынесена в чистый модуль [`src/editor/gestures.ts`](../src/editor/gestures.ts) (тап, двойной тап, долгое нажатие, щипок) и покрыта тестами. Обработка событий и всё, что трогает DOM, в [`EditorCanvas.vue`](../src/editor/components/EditorCanvas.vue).

## Проверить на планшете

- [ ] Один палец по пустому месту двигает холст, тап снимает выделение.
- [ ] Щипок масштабирует вокруг пальцев, два пальца двигают холст; поднять один и продолжить без скачка.
- [ ] Перетаскивание ноды и группы (с вложенными), изменение размера за грань и угол.
- [ ] Протянуть связь от пина к ноде и в пустое место (палитра); тап по пину ничего не создаёт.
- [ ] Долгое нажатие на пустом месте открывает палитру, клавиатура не выезжает.
- [ ] Двойной тап по связи ставит точку; двойной тап по полосе группы правит название.
- [ ] Режим «Выделение»: рамка и добавление тапами; «Удалить».
- [ ] Заметка: набор текста, клавиатура, не ломается ли раскладка холста.
- [ ] Автопрокрутка при перетаскивании к краю экрана.
- [ ] Долгое нажатие, поднять палец, снова коснуться пустого места и повести: холст едет, зум не включается (была ошибка: палитра открывалась под пальцем, и холст не узнавал, что палец поднят).
